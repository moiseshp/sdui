# Registro de decisiones

Formato: `ID · decisión · estado · motivo`. Estados: **vigente**, **descartada**, **deuda** (aceptada para la demo, a revisar si va a producción), **pendiente**.

Las decisiones descartadas se conservan para que nadie las vuelva a proponer sin contexto.
